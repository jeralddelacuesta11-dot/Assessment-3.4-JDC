ASSESSMENT 3.3 - NON-LINEAR DATA STRUCTURE
Name: DELA CUESTA
Language: Python
IDE: PyCharm

FILES
1. binary_tree_dela_cuesta.py
   - Builds a binary tree using all 10 letters of DELACUESTA.
   - Displays BFS and DFS (Preorder).

2. graph_dela_cuesta.py
   - Builds an undirected graph using the distinct letters.
   - Displays BFS and DFS, starting at D.

HOW TO RUN IN PYCHARM
1. Extract the ZIP file.
2. Open the extracted folder in PyCharm.
3. Open either .py file.
4. Click the green Run button.

No external packages are required.

EXPECTED OUTPUT - BINARY TREE
BINARY TREE - DELA CUESTA
BFS: D - E - L - A - C - U - E - S - T - A
DFS (Preorder): D - E - A - S - T - C - A - L - U - E

EXPECTED OUTPUT - GRAPH
GRAPH - DELA CUESTA
BFS: D - E - L - A - C - U - T - S
DFS: D - E - A - S - C - T - L - U

NOTE
For the binary tree, repeated letters are separate nodes because each
letter position in the surname is represented.
For the graph, each distinct letter is one vertex, so repeated letters
are represented by a single vertex.
